# 🛒 MyGroceryListTracker

A simple offline grocery list tracking app built with **Expo + React Native + TypeScript**.

---

## 📱 About the App

MyGroceryListTracker helps you manage grocery lists on your phone.  
It stores everything locally so it works **offline**.

Planned features include receipt scanning and smart item suggestions.

---

## ✨ Features

- 📝 Create and manage grocery lists
- ➕ Add, edit, and delete items
- ✔️ Mark items as purchased
- 💾 Offline storage using SQLite
- 📱 Mobile-friendly UI with Expo
- 📷 (Planned) Receipt scanning with camera
- 🔍 (Planned) Text recognition for receipts

---

## 🧱 Tech Stack

- Expo (React Native)
- TypeScript
- SQLite (expo-sqlite)
- React Navigation
- React Native Paper
- Expo Camera (planned)
- ML Kit Text Recognition (planned)

---

## ⚙️ Setup

### Install dependencies
```bash
npm install
````

### Start the app

```bash
npx expo start
```

---

## 📱 Run on phone

1. Install **Expo Go** from Play Store / App Store
2. Run the project
3. Scan the QR code

---

## 🗄️ Storage

The app uses **SQLite** for offline storage, so no internet is required.
